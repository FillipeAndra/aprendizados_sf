
## Básico e gerenciador de senhas

- As senhas de cada pessoa devem variar, sempre sendo diferentes para cada aplicação, não tendo um padrão que varia pouco 

- É considerado como recomendado que cada senha tenha no mínimo 12 caracteres

- Para usuários comuns é recomendado o uso de gerenciadores de senhas para auxiliar no processo de controles das diferentes senhas.

- A senha master do gerenciador de senhas é recomendado que tenha no mínimo 16 caracteres sendo formada por uma frase com letra maiúscula, minúscula, caractere especial, e números

- Outra boa prática é o uso de MFA para garantir a prevenção de acesso indevido

- Para senhas de contas administradoras é recomendado o uso de PAM (Privileged access management)

- para implementar em um sistema como Salesforce é necessário também pensar em um conjunto de boas práticas para acessos com mais privilégios como:

	- Tornar o MFA obrigatório para cada tentativa de acesso

	- Obrigar o uso de senhas longas compostas por uma frase com uso de caracteres especiais, letras maiúsculas, minúsculas e números 

	- tornar obrigatório a troca de senha a cada período de tempo determinado, informando por notificação a proximidade do período de troca de senha

	- deve ser realizado a aplicação de uma política de menor privilégio possível (POLP) para prevenir modificações e acessos indevidos

	- Deve ser realizado o monitoramento constante para encontrar atividades suspeitas de forma rápida e eficaz

	- tem que ter um processo de sanitização e desligamento caso haja saída do funcionário

	- pode ser implementado o controle acesso por tempo, onde o usuário só pode acessar durante certos períodos do dis em certos dias específicos

- Nunca coloque os acessos de api ou de sistemas em seus códigos, coloque eles no serviço de gerenciamento de segredos usados para o projeto ou pela empresa que você (desenvolvedor) trabalha

## PAM (Privileged access management)

- Uma ferramenta de gestão de acessos privilegiados que permite o controle de armazenamento de senhas, e chaves de criptografia, conseguindo auditar quem solicitou, e mantendo o log dos acessos.

- O PAM pode ser usado para fazer a definição do nível de acesso de cada usuário administrador para qual atividade ele tem que realizar, fazendo o controle de acesso deles

- Além de uma ferramenta de gestão o PAM é também um conjunto de regras e boas práticas para manter o controle e segurança referente à acessos privilegiados
