
## Definição

- Usuários são qualquer pessoa com login e senha para acessar o sistema do Salesforce

- No cenário do SalesForce podem existir diferentes tipos de usuários como:

	- Usuários administradores
	
	- Usuários de colaboradores como vendedores e desenvolvedores
	
	- Usuários externos como clientes ou possíveis clientes

## Itens do  cadastro de usuário

### Itens obrigatórios

- Nome de login / Nome de usuário (Pode ser um nomeque siga o padrão de um e-mail ou um endereço de e-mail. Ex de nome: clovis@atk68.com.  nome não precisa ser um e-mail real)

- Endereço de e-mail

- Sobrenome do usuário

- Apelido /Alias (É a forma como o nome do usuário parece para os outros no sistema)

- Licença (cada licença libera acesso à um subsistema ou sistema integrado. Um exemplo é o Chatter)

- Perfil (É a base de permissões de acessos de um usuário. O recomendável é liberar apenas o Minimum Access - Salesforce, e depois ir acrescentando as permissões que precisar)

### Itens opcionais

- Nome do usuário

- Papel do usuário (Cada usuário só pode ter um e ele serve para dar permissão de acesso a dados de outros usuários. Exemplo: o gestor do comercial tem acesso aos dados de seus vendedores e das leads deles) (Esta funcionalidade só está disponível nas edições Professional, Enterprise, Unlimited, Performance e Developer do Salesforce)

## Opções de configuração de usuário

### Como chegar na tela

- 1) Vá para a opção de configuração

- 2) Vá para a tela de usuários

### O que pode ser feito

- Criar usuários

- Redefinir senha para 1 ou múltiplos usuários selecionados simultaneamente

- Acessar os detalhes de usuário e editar

- Fazer acesso a uma conta selecionada no painel

## Primeiro acesso do usuário

- O usuário recebe um link temporário de acesso via e-mail para que ele defina sua senha. Caso  passe do prazo o administrador tem que redefinir a senha para que  o usuário faça login. 

## Cadastro de usuários

- O processo de cadastro pode ser feito para um único usuário ou vários de uma só vez

- O número máximo de usuários cadastrados é determinado pelo tipo de Salesforce da emrpesa.

### Passo à passo

- 1) Clique em configuração

- 2) Clique em busca rápida (Quick find) e digite "Users" ou "Usuários"

- 3) Clique em novo usuário ou Adicionar vários usuários

 - 4) Digite  o último nome do usuário, 
	 - O apelido dele, 
	 - O e-mail 
	 - O login (recomendo o e-mail com nome dele na atacado68), 
	 - Selecione o papel dele, 
	 - Selecione a licença associado ao usuário, 
	 - Escolha também o perfil dele,
	 - Selecione o usuário como ativo ou não 
	 - Selecione ou não Marketing User para permitir que o usuário crie, gerencie e impulsione campanhas de marketing

- 5) Selecione Gerar uma senha e notificar imediatamente o usuário (Generate password and notify user immediately) para mandar o e-mail para criação de senha do usuário

- 6) Clique em salvar

## Congelar um usuário

- Como administrador é possível que você receba um e-mail informando que a conta de um usuário pode ter sido comprometida ou

- Para desabilitar a conta de um colaborador é preciso:

### Passo à passo

- 1) Selecione o campo de configuração

- 2) Selecione busca rápida e pesquise por Usuários

- 3) Clique no nome da conta do usuário que deseja que seja desabilitado

- 4) Selecione a opção Freeze ou congelar para impedir o login do usuário

## Desativar / Desabilitar um usuário

- Processo para impedir uma conta de efetuar login e que também libera as licenças de usuário para que a empresa possa aplicar em outro usuário.

- Recomendado em caso de desligamento de um colaborador

- Não é possível excluir um registro de usuário

### Passo à passo

- 1) Selecione o campo de configuração

- 2) Selecione busca rápida e pesquise por Usuários

- 3) Selecione o usuário que deseja desativar

- 4) Desmarque a caixa de ativo


## Controle de acesso

- Processo de controle de acesso de um usuário aos recursos e também controle das permissões que ele detém dentro da empresa

### Passo à passo

- 1) Selecione o campo de configuração

- 2) Selecione busca rápida e pesquise por Usuários

- 3) Selecione o usuário desejado

- 4) Clique em exibir resumo (View Sumary)

- 5) Navegue ao longo das guais como a de acesso concedido por para verificar os acessos do usuário e editá-los caso necessário.

	- O controle de acesso depende das permissões associadas ao usuários e também depende dos grupos ou  filas que o usuário esteja presente
