
### Termial

- sf org list: listas as organizações logadas, com o usuário e o alias da org criado no momento do cadastro

- sf org login web: abre uma guia do salesforce no navegador de escolha para logar na organização desejada

- sf project deploy start --target-org {id do usuário da organização desejada ou o alias dela}: faz upload do LWC para a organização desejada 

- sf lightning dev component --target-org {id do usuário da organização desejada ou o alias dela}: instala os plugins para testes locais (se for a primeira vez usando o comando) e mostra no navegador as modificações que estão sendo feitas no componente (apenas em 1).

- sf lightning preview vs code extension: instala os plugins para testes locais (se for a primeira vez usando o comando) e mostra no vscode as modificações que estão sendo feitas no componente do lightning (apenas em 1) ou no componente em react (apenas em 1).

### Vscode

1) para permitir acionar os comandos das extensões do Salesforce é preciso usar primeiro o seguinte atalho:

	- Ctrl+shift+p

2) quando o campo de pesquisa do VScode se assemelhar ao presente na foto abaixo pode-se começar a usar a lista de comandos que se segue.

	![[atalhos_comandos_vscode.png]]


	- SFDX: Create Project (serve para criar um projeto padrão para o ambiente salesforce)
	
		- primeiro se coloca o tipo do projeto (Standard, Empty, etc), depois o nome do projeto e depois seleciona a pasta que ele vai ficar
	
	- SFDX: Create Lightning Web Component (usado para criar um componente LWC dentro de um projeto já criado)
	
		- primeiro coloca o nome do componente que deve ser criado e depois a localização de onde ele deve ser criado (geralmente se utiliza a pasta padrão)
