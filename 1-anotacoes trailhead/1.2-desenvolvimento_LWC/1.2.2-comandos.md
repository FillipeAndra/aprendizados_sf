
### Termial

se você quiser ver o retorno detalhado com todo o texto de todos os comandos de listagem ou se quiser ver a mensagem de erro dos comandos de ação use "--json" no final dos comandos.

- sf org list: 

	- listas as organizações logadas, com o usuário e o alias da org criado no momento do cadastro

- sf org login web: 

	- abre uma guia do salesforce no navegador de escolha para logar na organização desejada

- sf config set target-org <username_ou_alias>: 

	- torna a org desejada na org padrão (default) 

- sf config set target-dev-hub=<username_ou_alias>:

	- torna a org desejada como a org DevHub padrão (default)

- sf project deploy start --target-org {id do usuário da organização desejada ou o alias dela}: 

	- faz upload do LWC para a organização desejada 

- sf org open --target-org <username_ou_alias>:

	- abre no navegador a organização desejada (podendo ser até uma scratch org)

- sf plugins install @salesforce/plugin-lightning-dev:  
	
	- instala os plugins para testes locais (se for a primeira vez usando o comando) e mostra no vscode as modificações que estão sendo feitas no componente do lightning (apenas em 1) ou no componente em react (apenas em 1).
	
	- ainda é preciso instalar a extensão do vscode para preview que é: 
	
		- Salesforce live preview 
	
	- para funcionar precisa fazer o seguinte:
	
		1) vá no config/project-scrath-def.json
		
		2) dentro da sessão  "lightningExperienceSettings" adicione a seguinte linha (lembre-se de colocar a vírgula no anterior, caso exista algo antes.):
		
			- "enableLightningPreviewPref": true

- sf org create scratch --definition-file config/project-scratch-def.json --alias <a_que_voce_desejar(use_camelCase)> --target-dev-hub <alias_ou_id_da_org_conectada>:

	- cria uma organização cópia (para homologação) da sua DevHub que é a org de produção

- sf lightning dev app --target-org <alias_ou_username> --device-type desktop:

	- comando usado para exibir um ambiente de preview com atualização em tempo real voltado para o ambiente de desktop no seu navegador
	
	1) se for a primeira vez pede aparecer uma pergunta para autorizar o uso da ferramenta que deve ser autorizado
	
	2) caso não apareça ou ao passar desse ponto selecione o app do ambiente que deseja rodar e aperte enter
	
	3) caso não funcione, faça do jeito padrão de atualizar, fazer um novo update e fechar a guia atual e abrir de novo 



### Vscode

1) para permitir acionar os comandos das extensões do Salesforce é preciso usar primeiro o seguinte atalho:

	- "Ctrl"+"shift"+"p"

2) quando o campo de pesquisa do VScode se assemelhar ao presente na foto abaixo pode-se começar a usar a lista de comandos que se segue.

	![[atalhos_comandos_vscode.png]]


	- SFDX: Create Project (serve para criar um projeto padrão para o ambiente salesforce)
	
		- primeiro se coloca o tipo do projeto (Standard, Empty, etc), depois o nome do projeto e depois seleciona a pasta que ele vai ficar
	
	- SFDX: Create Lightning Web Component (usado para criar um componente LWC dentro de um projeto já criado)
	
		- primeiro coloca o nome do componente que deve ser criado e depois a localização de onde ele deve ser criado (geralmente se utiliza a pasta padrão)
