
- Plataforma de desenvolvimento lowcode interna da salesforce focada na criação de pequenas automações

## Acesso e edição

- para conseguir ativar e ver o app funcionando mesmo estando como admin, é preciso entrar no setup, pesquisar por Login Access Policies > permitir a opção Administrators can log in as any user e salvar. 
1) Para acessar a tela do flow é preciso clicar no **App Laucher**  ![[app_launcher.png]]

2) Pesquisa por automation e o app **FLOW** vai estar disponível

3) clique em **new** para inicar a criação de um novo flow

4) Neste cenário trataremos da opção **screen flow** que aparece na parte mais abaixo do painel de seleção de do **Frequently used**

5) para adicionar um novo elemento seleciona-se o ícone: ![[novo_elemento.png]]

6) pesquise e/ou selecione o tipo de nodo que deseja adicionar (neste cenário será utilizado o novo Activate Session-Based Permition Set para indicar o sales force que um sessão está ativa para liberar uma permission set)

7) Quando se cria um nodo, é preciso primeiro adionar o rótulo, depois o nome comum de API vem automático

8) Então no campo de set input values neste cenário se coloca o nome de API do permission set que tem a configuração de ser session-based e então salve

9) coloque o nome que deseje para o flow

10) Para fazer o flow funcionar existem duas formas: clicar no botão **run** para fazer um teste ou clicar no botão de **activate** para deixar a automação em atividade por tempo indeterminado

### Liberando acesso aos usuário acessarem a automação do flow

1) acesso a organização como admin e entre em setup, no quick find digite por user management settings (gerenciamento de configurações de usuário) e permita o enhanced profile user interface

2) no quick find pesquise por profile e e selecione o perfil para o qual deseja liberar a tela de flow

3) na caixa de find settings dentro do perfil procure por lightning expirience user, edite a opção, dê permissão e salve.

4) na caixa de find settings dentro de perfil, procure por manage flow. Edite a configuração dentro de app permissions, libere a opção e salve.

## Integrando as automações com telas criadas para os usuários

- é possível criar interfaces para os usuários de sua organização sales froce consigam utilizar aplicações ou automações criadas em outros aplicativos como o automation citado anteriormente

- uma das formas de criar essas interface é utilizando o aplicativo **Lightning app** 


### Uso do Lightning App 

1) entre como admin na organização, depois pesquise por builer no quick find e selecione o **Lightning app Builder**

2) clique em **new** e selecione **App page** e clique em **next** 

3) Dê um nome para a página, clique em **next**, selecione **One Region** e clique em **done**

4) Na área de components no canto esquerdo digite por flow na barra de pesquisa e arraste o elemento do flow para a área demarcada de Add components here ou arraste para o topo da parte central da tela de edição (canvas)

5) selecione o flow component que foi adicionado no canvas e na tela de edição do componente no lado direito da tela pesquise pelo nome do flow que deseja adicionar e clique em **save** e depis em **activate** caso deseje acionar a tela

6) na tela de ativação vá para opção de Lightning Experience > Dentro do campo **Add to Lightning apps** selecione aplicativo desejado a qual se escolha associar a nova tela e selecione a opção **Add page to App**

7) Por fim aperte save
