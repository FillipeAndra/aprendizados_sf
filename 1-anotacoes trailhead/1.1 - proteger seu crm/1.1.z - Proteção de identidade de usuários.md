
## Métodos de autenticação de múltiplos fatores

- aplicação de métodos para verificar a autenticidade de um usuário além do métodos padrão de usuário e senha (padrão de eu sei)

- uma das foras de autenticação de múltiplos fatores  (podendo ser 2 ou mais), que compõem o processo além do login padrão é o padrão do eu tenho que geralmente é composto por um token que vai alterando seu valor ao longo do tempo.

### Métodos de autenticação de múltiplos fatores presente na SalesForce

- SalesForce Authenticator: aplicativo gerador de valor de token da sales force

- Aplicativos autenticadores TOTP: Google Authenticator, Microsoft Authenticator, Proton 2FA, etc.

- Chave de segurança: um token físico que se assemelha a um pen drive que ao ser conectado ao computador e selecionado a opção de autenticação seguindo essa forma ele permite a entrada do usuário.  A chave tem que ser compatível com o protocolo FIDO ou FIDO2.

- Autenticadores embutidos: uso de autenticadores de reconhecimento de digital ou de face. Pode também ser usados senhas ou pins que o usuário usa no sistema operacional da máquina.

### Momentos de requisição de MFA no ambiente Sales Force

- login dos usuários (mínimo obrigatório, pois o Salesforce exige isso)

- quando os usuários acessas alguma API do Salesforce

- quando os usuários tentam acessar um relatório, um painel ou um aplicativo específico conectado

- na entrada de um aplicativo personalizado.

### Como habilitar o MFA para toda a emrpesa

- Por padrão ele vem ativo, caso ele esteja desativado para o acesso do usuário, é possível reabilita-lo.

- 1) Verifique se o nível de segurança para o MFA está ativo, indo para a parte de Setup (configuração), pesquisar por Session Settings e acesse esta configuração

- 2) Observe se o campo de autenticação multifator está marcado na categoria Alta garantia

- 3) Para habilitar o MFA para todos da organização vá em Setup e procure por Identity (identidade) e selecione Identity verification (verificação de identidade)

- 4) Marque a caixa: require multi-factor authentication (MFA) for all direct UI logins ... (Exigir autenticação multifator para todos os logins diretos de interface do usuário ...)

- 5) Clique em Salvar

### Como o usuário cadastra o MFA

- 1) Faça o primeiro acesso de login e configure a senha da conta


- 2) instale o SalesFoce authenticator no celular. ele usa o seguinte logo:

![[sales_force_logo.png]]

- 3) Avance nas telas do aplicativo até chegar na etapa onde aparece uma frase código para conectar com a conta

- 4) no computador faça login na conta e chegue na tela de colocar o código

- 5) insira o código presente no aplicativo no campo que o está solicitando no computador

- 6) agora o aplicativo vai enviar notificações quando houver uma tentativa de acesso com a conta. Caso seja o próprio usuário autenticando ele só precisa autorizar, caso não, ele rejeita o acesso.

- 7) Para permitir notificações no salesforce authenticator é preciso ir na parte de configurações no canto superior esquerdo, e permitir a seção de push notifications (Notificações psuh)

#### Informações coletadas pelo SalesForce Authenticator

- Localização do celular com o app para permitir o login automático quando o celular estiver próximo de quem está tentando acessar

- qual o nome do usuário que está tentando realizar o login

- o serviço que o usuário está tentando acessar

- informações do navegador que está sendo usado para realizar acesso no desktop

### Fazendo backup da autenticação das contas conectadas (usuário que faz)

1) No app do salesforce authenticator vá na aba de configurações no canto superior esquerdo

2) Toque no botão back up accounts (fazer backup de contas)

3) digite o endereço de e-mail que vai servir de backup e clique para enviar o código de verificação 

4) digite o código recebido no e-mail no campo destinado no salesforce authenticator

5) Vai ser solicitada uma senha numérica de 4 dígitos para ser usada posteriormente caso precise recuperar os tokens de verificação.

### Permissão de acesso por localização e máquina

- é possível realizar o processo de verificação e autenticação sem necessariamente apertar no celular para permitir. Para isso é preciso fazer:

1) liberar o acesso à localização o tempo todo do app salesforce authenticator no celular

2) realizar o login no computador que geralmente se trabalha (estando com o celular com o autenticador perto)

3) na tela do aplicativo no celular é preciso permitir a opção confiar e automatizar esta solicitação. Assim toda vez que o usuário logar nesta conta, nesta máquina, na posição geográfica atual, com o celular por perto, a pessoa só vai precisar colocar a senha.

	3.5) para aparelhos que bloqueiam a localização se estiverem bloqueados é preciso desbloquear a tela para autenticar.

4) para adicionar uma automação nova faz-se o mesmo procedimento citado anteriormente

5) caso queira remover uma automação, é preciso entrar no token com a conta no salesforce authenticator através da seta apontando para a direita
	
	- depois selecionar a automação
	- e então selecionar o botão remover automação

6) caso queria retirar todas as automações de uma vez ela entra no token

	 - depois vai no ícone de engrenagem no canto superior direito  
	 - e seleciona remover todas as solicitações automatizadas

7) caso a conexão não funcione como normalmente, só é preciso inserir o conjunto de números exibido no token da conta (esses números se alteram em média a cada 1 minuto)

### Bloqueando verificação de 2 fatores automáticas para todos os usuários ou restringindo

- é possível bloquear as verificações MFA automatizadas ou restringi-las para os endereços de rede confiáveis (endereços de rede da empresa)

1) Para isso é preciso logar como adm e depois ir na parte de settings, e pesquisar por identity verification no quick search

2) Caso queria apenas restringir o login automatizado devido ao endereço de IP, pode-se habilitar ambas as opções de "Let Salesforce Authenticator automatically verify identities using geolocation" e a de "Let Salesforce Authenticator automatically verify identities based on trusted IP addresses only"

3) Caso queira desabilitar o MFA automatizado, basta desmarcar ambos os campos.

### Recuperando o autenticador em caso de perda do aparelho celular

- Tem duas maneiras principais: caso o usuário tenha feito o backup e cadastrado a senha desejada, ele pode recuperar sozinho, caso não é preciso que o admin desconecte a conta do usuário do salesforce authenticator para que ela possa registrar i aplicativo novamente.

#### Caso o usuário tenha feito o backup

1) Logo após o usuário instalar o aplicativo no novo aparelho ele precisa selecionar a opção de "restaurar suas contas do backup"

2) O usuário então digita a senha numérica de 4 dígitos que tinha cadastrado anteriormente e os tokens das contas anteriormente cadastradas são alocadas no novo aparelho

#### Caso o usuário não tenha feito o backup

1) ao entra como adiministrador vá no setup e no quick find procure por users e selecione a opção

2) pesquise pelo usuário que está solicitando a recuperação dos tokens e selecione a conta dele

3) selecione a opção "desconectar" ao lando do campo: "App Registration: Salesforce Authenticator" 

### Verificar histórico dos logins

1) Logue como admin, vá no setup e no quick find digite "identity verification history"

2) Então é possível ver uma tabela de acessos e logins dos usuários na plataforma


## Politicas de senha

- Elas são editadas na password policies 

- É possível alterar em quantos dias as senhas dos usuários expiram

- É possível editar quantas senhas ele lembra para que o usuário não repita suas senhas

- É possível editar o grau de complexidade da senha

- A quantidade máxima de logins antes do bloqueio e quanto tempo a pessoa passa bloqueada

- É possível Impedir que que os usuários troquem a senha mais de uma vez por dia com o Require a minimum 1 day password lifetime 

## Controle de acesso via IP

- após analise, foi entendido que ambos os cenários de restrição ou permissão de IP precisa de cuidado. Em ambos os cenários ele trabalha com o ip externo, então é preciso criar 1 registro de ip para cada endereço de roteador usando na empresa. Nesse cenário cada endereço vai do ip de seu roteador até o seu mesmo endereço. 

### Isenção do MFA por endereço IP

- é possível configurar que os usuários não precisam usar o MFA se eles estiverem acessando através um range de endereço IP

1) acesso o salesforce como admin, vá em Setup e pesquise por Network Access no quick find

2) clique em novo

3) insira o inicio e o fim do range de endereços IP que sejam confiáveis e clique  em salvar

### Restringir acesso para apenas os IPs permitidos

- É possível impedir que os usuários façam acesso caso eles não estejam em um range de IP 

1) acesso o salesforce como admin, vá em Setup e pesquise por profiles no quick find

2) clique no nome do perfil que deseja editar

3) vá no item intervalos de ip de login (login ip ranges) e clique editar

4) Insira o range de ip externo que pode acessar sua organização salesforce
